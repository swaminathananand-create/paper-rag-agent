# ReAct: Synergizing Reasoning and Acting in Language Models

Authors: Shunyu Yao, Jeffrey Zhao, Dian Yu, Nan Du, Izhak Shafran, Karthik Narasimhan, Yuan Cao
Affiliation: Princeton University, Google Research, Google Brain
Year: 2022

## Abstract
While large language models (LLMs) have demonstrated impressive capabilities across tasks in language understanding and interactive decision making, their strategies for doing so are often separate: language models excel either at reasoning tasks (e.g., chain-of-thought prompting) or at acting in interactive environments (e.g., WebGPT, SayCan). We explore the use of LLMs to generate both reasoning traces and task-specific actions in an interleaved manner, allowing for greater synergy between the two: reasoning traces help the model induce, track, and update action plans as well as handle exceptions, while actions allow it to interface with and gather additional information from external sources such as knowledge bases or environments.

## 1. Introduction and Main Argument
Our main argument is that reasoning and acting should not be treated as independent facets of language model behavior. Instead, the interleaving of Thought → Action → Observation triplets within a single unified prompting framework — which we term ReAct — allows language models to simultaneously plan and execute, adapt based on real feedback, and produce more accurate, grounded, and interpretable decision-making behavior than either capability achieves in isolation.

## 2. Methodology
ReAct is a simple yet powerful prompting approach. Given a task, the LLM is prompted to produce interleaved sequences of:
1. Thought: A textual reasoning trace analyzing the current situation and planning the next step.
2. Action: A concrete action taken (e.g., Search[query], Lookup[term], Finish[answer]).
3. Observation: The external feedback received from the environment (e.g., Wikipedia search result, tool API response).
We evaluate ReAct on diverse benchmarks:
- HotpotQA (multi-hop QA requiring multi-step retrieval)
- FEVER (fact verification from Wikipedia)
- ALFWorld (household robotic task planning in a text-based simulation)
- WebShop (interactive online shopping agent)
Both few-shot prompting and fine-tuning regimes are evaluated.

## 3. Key Findings
On HotpotQA, ReAct outperforms chain-of-thought (CoT) prompting alone and action-only prompting (Act), achieving the highest exact match scores.
On FEVER, ReAct significantly reduces hallucination rate by grounding claims via retrieved Wikipedia passages.
On ALFWorld, ReAct achieves a 71% success rate on unseen tasks, dramatically outperforming imitation-learning baselines (37%).
On WebShop, ReAct scores 40.2 (vs. IL+RL baseline of 28.7 and CoT of 33.9), demonstrating strong generalization to practical agentic tasks.

## 4. Implications & Broader Significance
ReAct introduces a paradigm for transparent, interpretable, and auditable AI reasoning in agentic systems. By externalizing the reasoning process as a visible thought trace, ReAct makes it possible to diagnose failure modes, detect hallucinations, and maintain human oversight over automated agents operating in dynamic environments. Its influence on the design of production LLM agent frameworks (LangChain, LangGraph, AutoGPT) has been foundational.
